Distribution Analysis Guide
Overview

The Distribution Analysis tool allows you to compare polygenic score distributions in two ways:

  • Compare Cohorts: View how the same PGS varies across different population groups
  • Compare PGS Scores: Compare distributions of multiple PGS for the same cohort
Analysis Types
1. Compare Cohorts (Same PGS)

Purpose: Compare how a single polygenic score is distributed across different population groups or custom cohorts.

Steps:

  1. Select "Compare Cohorts" from Analysis Type
  2. Choose a PGS ID from the dropdown
  3. Select a score type (SUM, Z_MostSimilarPop, Z_norm1, or Z_norm2)
  4. Select cohorts from the available options
  5. Generate your visualization
Tip: This is ideal for studying differences between population groups or identifying patterns across different study cohorts.
2. Compare PGS Scores (Same Cohort)

Purpose: Compare distributions of multiple PGS within the same population group.

Steps:

  1. Select "Compare PGS Scores" from Analysis Type
  2. Choose a cohort from the dropdown
  3. Select a score type (all PGS will use the same type)
  4. Select multiple PGS IDs from the available options
  5. Generate your visualization
Tip: Useful for comparing related traits or validating multiple PGS for the same phenotype.

Available Cohorts

Cohorts are pre-defined groups of samples that allow you to compare distributions across different populations or study groups. These cohorts are created using the Indiana Biobank system and are imported into the system. We automatically load the computed ancestry cohorts in every session.

Score Type Selection

Choose the appropriate normalization based on your analysis goals:

SUM

Raw polygenic score values. Use when you need the actual calculated scores without normalization.

Z_MostSimilarPop

Normalized by ancestry group. Best for cross-population comparisons.

Z_norm1

Continuously normalized for mean. Use for ancestry-adjusted analyses.

Z_norm2

Normalized for both mean and standard deviation. Most standardized form.

Typical Workflow
  1. Choose Analysis Type: Decide whether to compare cohorts or PGS scores
  2. Select Data: Pick your PGS ID(s) and/or cohort(s)
  3. Configure Visualization: Choose chart type and score normalization
  4. Generate Plot: Create your interactive visualization
  5. Explore Results: Use the interactive features, view metadata, and download data
  6. Export: Save your plots as HTML or view in new tab for presentations
