Odds Ratio
Will only work with exactly 2 subcohorts.
How it works:
  • For each bin i:
    • Define Ti as the lower bound of bin i
≥ Ti < Ti
Subcohort 1 Ai Bi
Subcohort 2 Ci Di
  • (ORi) = ((Ai + ε) × (Di + ε)) / ((Bi + ε) × (Ci + ε)) where ε = 0.5
  • Log Odds Ratio = ln(ORi)
  • Standard Error = √(1/(Ai+ε) + 1/(Bi+ε) + 1/(Ci+ε) + 1/(Di+ε))
  • 95% CI = exp(ln(ORi) ± 1.96 × SE)
How it works:
  • For each quantile q:
    • Define Qq as the score at quantile q
≥ Qq < Qq
Subcohort 1 Aq Bq
Subcohort 2 Cq Dq
  • (ORq) = ((Aq + ε) × (Dq + ε)) / ((Bq + ε) × (Cq + ε)) where ε = 0.5
  • Log Odds Ratio = ln(ORq)
  • Standard Error = √(1/(Aq+ε) + 1/(Bq+ε) + 1/(Cq+ε) + 1/(Dq+ε))
  • 95% CI = exp(ln(ORq) ± 1.96 × SE)
How it works:
  • For a single threshold T:
    • Define contingency table for values above and below threshold
≥ T < T
Subcohort 1 A B
Subcohort 2 C D
  • OR = ((A + ε) × (D + ε)) / ((B + ε) × (C + ε)) where ε = 0.5
  • Log Odds Ratio = ln(OR)
  • Standard Error = √(1/(A+ε) + 1/(B+ε) + 1/(C+ε) + 1/(D+ε))
  • 95% CI = exp(ln(OR) ± 1.96 × SE)
How it works:
  • For each decile d (from 1 to 10):
    • Define Dd as the set of values in decile d
In Decile d In Decile 1 (baseline)
Subcohort 1 Ad A1
Subcohort 2 Cd C1
  • For d=1: OR1 = 1.0 (baseline)
  • For d>1: ORd = ((Ad + ε) × (C1 + ε)) / ((Cd + ε) × (A1 + ε)) where ε = 0.5
  • Log Odds Ratio = ln(ORd)
  • Standard Error = √(1/(Ad+ε) + 1/(Cd+ε) + 1/(A1+ε) + 1/(C1+ε))
  • 95% CI = exp(ln(ORd) ± 1.96 × SE)
How it works:
  • For each decile d (from 1 to 10):
    • Define Dd as the set of values in decile d
    • Define D<d as the set of values in all deciles lower than d
In Decile d In All Lower Deciles
Subcohort 1 Ad A<d
Subcohort 2 Cd C<d
  • For d=1: OR1 = 1.0 (no comparison group)
  • For d>1: ORd = ((Ad + ε) × (C<d + ε)) / ((Cd + ε) × (A<d + ε)) where ε = 0.5
  • Log Odds Ratio = ln(ORd)
  • Standard Error = √(1/(Ad+ε) + 1/(Cd+ε) + 1/(A<d+ε) + 1/(C<d+ε))
  • 95% CI = exp(ln(ORd) ± 1.96 × SE)
