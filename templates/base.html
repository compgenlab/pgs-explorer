PGS Visualizer - A tool for exploring Polygenic Score data

Create New Database
Enter a unique name for your database (will be used as folder name)
Upload a tab-separated scores file (plain text or gzipped). Expected format: First column = PGS_ID, Second column = SCORE_TYPE, remaining columns = sample scores with headers as sample IDs.
Optional CSV file with PGS metadata. Should include columns like PGS_ID, PGS_Name, Reported_Trait, etc.
Scores File Format:
• First row should contain headers: PGS, SCORE_TYPE, then sample IDs
• Each subsequent row: PGS_ID, score_type, then numeric scores for each sample
• Files can be plain text (.tsv, .txt) or gzipped (.gz)

Processing Time: Large files may take several minutes to process. You'll receive a notification when complete.
Note: This will create a permanent database that will be available across all sessions until manually deleted.
Add Temporary Score Data
Enter a unique PGS ID for your temporary data
Enter the trait name for this PGS
Upload a tab-separated file (plain text or gzipped) with columns: sampleset, FID, IID, PGS, SUM, Z_MostSimilarPop, Z_norm1, Z_norm2, percentile_MostSimilarPop
Expected format: Tab-separated file with headers: sampleset, FID, IID, PGS, SUM, Z_MostSimilarPop, Z_norm1, Z_norm2, percentile_MostSimilarPop
Note: Temporary score data is only available during your session and will be removed when you clear your session or after the specified time period.
